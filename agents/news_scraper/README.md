# News Scraper

Phase 0 RSS pipeline for ContentCreation-OS.

## Run
### Activate Python Environment
From the project root:
```powershell
.venv\Scripts\Activate.ps1
```
Prompt should show `(.venv)`. Then:

```powershell
python -m agents.news_scraper.run
python -m agents.news_scraper.run --dry-run
python -m agents.news_scraper.run -v

# Static HTML digest (open in browser)
python -m agents.news_scraper.view
```

## Inputs

- `config/news_sources.yaml` — feed URLs, categories, keyword filters

## Outputs

- `data/news/YYYY-MM-DD.json` — filtered items for the day
- `data/news/digest.html` — static HTML viewer (generated by `view`)
- `data/news/seen.json` — URL hashes for deduplication

## Contract

```python
from agents.news_scraper.run import run_pipeline

result = run_pipeline(dry_run=False)
# result.kept, result.output_path, ...
```

Each output item is a `core.models.NewsItem` with `processing.status` of `filtered` or `discarded`.
